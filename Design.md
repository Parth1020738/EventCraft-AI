# Design System & Styling Guidelines

## Color Palette
- **Primary / Festive Accent:** Deep Indigo (`#4F46E5`) & Royal Violet (`#7C3AED`)
- **Secondary / Celebration Accent:** Warm Amber (`#F59E0B`) & Rose (`#F43F5E`)
- **Backgrounds:** Warm White (`#FAFAFA`) for Light Mode; Rich Slate (`#0F172A`) for Dark Mode
- **Text:** Slate 900 (`#0F172A`) for primary headers; Slate 600 (`#475569`) for body text

## Typography
- **Primary Font:** Inter / System UI (`font-sans`)
- **Display / Heading Accent:** Plus Jakarta Sans (`font-heading`)

## Component Styling Rules
- **Cards:** White background, rounded border (`rounded-xl`), smooth elevation shadow (`shadow-sm hover:shadow-md`).
- **Buttons:** High-contrast primary call-to-actions with distinct `:focus-visible` ring outlines for accessibility.
- **Badges:** Pill-shaped tags (`rounded-full`) with light pastel backgrounds for status indicators.
